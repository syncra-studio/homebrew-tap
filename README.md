# Syncra Studio Homebrew tap

```sh
brew install --cask syncra-studio/tap/brigadier
```

[Brigadier](https://github.com/syncra-studio/brigadier-ai) runs Claude Code and Codex as one team on
your Mac. macOS 14 or later, Apple silicon or Intel. The app updates itself once installed.

Uninstall with `brew uninstall --cask brigadier`; `brew uninstall --zap --cask brigadier` also
removes its data. Prefer the app's own **Uninstall Brigadier…** (menu bar or Settings › Storage)
first: it also removes the worktrees and session files it made in your projects.
